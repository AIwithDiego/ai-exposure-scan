Proposal · Shield theme

A dark, protective look for AI Exposure Scan

Near-black violet surfaces, one warm orange accent for action and danger, violet and teal for information and safety. Every component below uses the class names that dashboard/src/App.jsx already renders, so restyling is mostly a stylesheet swap.

See components Get the CSS

00Principles

Owners of small sites read this dashboard. It should feel like a security tool, but never shout more than the finding deserves.

One loud colour
  • Orange-red means "act now": primary buttons, the active nav item, high severity, poor scores.
  • Nothing decorative is orange.
Calm by default
  • Info and pass states use violet, gray and teal.
  • Glows only sit on accents, never on whole panels.
Evidence is literal
  • URLs and snippets are always monospace on an inset surface, so it is clear what was actually seen.
Thin lines, soft corners
  • 1px violet-gray borders, 8–10px radius, generous 24px panel padding.
  • Hexagon and radar motifs for brand moments only.

08Method badges

"Detected" is solid: plain code found it. "Judged" is a dashed violet outline: a model or heuristic decided, so treat it as a second opinion. The dash carries the meaning without colour.

detected judged · mediumjudged
Classes

  • .method.method-judged — transparent, 1px dashed violet, cursor: help
